Repo History
•You can find out all all your project history using 
git log.
•And you can exit git log using Q.
•Each commit has unique ID, Or Hash Number of this commit.
•You can Go back to any version or commit using 
git checkout <HASH-NUMBER>
And HEAD will change to this commit

What is Git Head
"HEAD" in Git is a pointer to the latest commit in the branch you're currently working on. It's 
like a bookmark indicating where you are in the project's history.
Note that the last commit named Master Or main
After checkout to commit C3 Head will be on C3 and so. 

Git ignore
•Why git ignore?
You will need no ignore any changes into some files or directories
for example files with security issues 
or directories and files with large size
•If you already Added file to be tracked you can remove it from git 
cache to ignore any changes using 
git rm--cached <File-Name>
•So now this file status will change to be untracked

Git ignore
•To preserve keeping this file untracked and ignore any changes
we will create file named .gitignore
•Add all files name you want to ignore it into this files
•You can ignore group of files with specific extension like all txt files 
by ignore 
*.txt
