Php Sessions –starting and set value
•A session is a way to store information (in variables) to 
be used across multiple pages.
•Unlike a cookie, the information is not stored on the 
users computer.
•A session is started with the session_start() function.
<?php
// Start the session
session_start();
?>

Get PHP Session Variable Values
<?php
// Echo session variables that were set on previous page
echo"Favorite color is ".$_SESSION["favcolor"] .".<br>";
echo"Favorite animal is ".$_SESSION["favanimal"] .".";
?>
all session variable values are stored in the global $_SESSION variable:

Modify a PHP Session Variable
<?php
// to change a session variable, just overwrite it
$_SESSION["favcolor"] ="yellow";
print_r($_SESSION);
?>
Destroy a PHP Session
<?php
// remove all session variables
session_unset();
// destroy the session
session_destroy();
?>
